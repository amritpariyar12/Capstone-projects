# 🎓 Smart Student Safety & Tracking System
A web-based student safety and tracking system designed to connect students, parents, teachers and drivers through a single platform.

This project was developed as an academic capstone project to explore React, role-based interfaces, student attendance management and
college bus tracking.

## ✨ Main Features
- 👨‍🏫 Teacher dashboard
- 👨‍🎓 Student dashboard
- 👨‍👩‍👧 Parent dashboard
- 🚌 Driver dashboard
- 📋 Student management
- 📅 Student attendance
- 🚌 College bus route and tracking
- 📊 Reports and dashboard information
- 👥 Role-based user interfaces
- 🇳🇵 Bikram Sambat calendar support
- 📱 Responsive frontend interface

## 👥 User Roles
### Teacher
- Manage students
- View attendance
- View reports
- Manage student-related information
### Student
- View personal information
- View attendance
- View bus route information
### Parent
- View children's attendance
- View student information
- View bus-related information
### Driver
- View assigned bus information
- Manage bus-related activities
  
## 🛠️ Technologies Used
- React
- JavaScript
- React Router
- Recharts
- CSS
- Bootstrap / frontend UI libraries
- Bikram Sambat calendar library

## 📌 Project Objective
The main objective of this project is to create a centralized platform
for managing student safety, attendance and transportation-related
information for an educational institution.
